# Linear Algebra Practice

This repository contains a collection of Python scripts demonstrating various fundamental linear algebra operations using the [NumPy](https://numpy.org/) library. These scripts serve as practice and reference for basic vector and matrix computations.

## Contents

- **Vectors**: Addition, subtraction, magnitude, dot product.
- **Matrices**: Addition, subtraction, scalar multiplication, element-wise multiplication, matrix multiplication, identity matrix operations.
- **Advanced Operations**: Transpose, inverse, determinant, eigenvalues and eigenvectors, and solving systems of linear equations.
- **Challenges**: Verification and combination of multiple concepts (e.g., `challenge.py`, `practice.py`).

## Prerequisites

To run these scripts, you will need Python installed along with the `numpy` library. 

You can install `numpy` using pip:

```bash
pip install numpy
```

## Running the Scripts

Each script is standalone and can be executed directly from the terminal. For example:

```bash
python dotProduct.py
python challenge.py
```
